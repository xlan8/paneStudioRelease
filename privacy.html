Privacy Policy

Effective date: October 7, 2026 · Applies to Pane Studio Workspace (Microsoft Store and direct-download versions)

In one sentence: Pane Studio Workspace works entirely on your own files on your own computer. We never see your documents, and we never sell data — there is no advertising in the app and no account system.

What the app stores (and where)

Everything the app produces stays on your device: workspace layouts, pane settings, working copies of edited documents, and preferences. None of this is uploaded to us or to any third party. There is no sign-up, no login, and no account, so we hold no personal profiles.

Anonymous usage analytics (Microsoft Clarity)

Released versions of the app report anonymous product-usage statistics through Microsoft Clarity, to learn which features are used and find crashes:

  • Collected: interaction events (clicks, scrolls), app version, Windows version, display size, approximate country/region derived from IP, and similar technical diagnostics.
  • Not collected: the contents of any file or folder you open, the addresses of pages you visit in web panes, text you type, or any name, email, or identifier that could directly identify you.
  • Used for: product improvement only. The data is not used for advertising and is not sold or shared with advertisers.

This data is handled by Microsoft under the Microsoft Privacy Statement.

Update checks

The direct-download version contacts our update server periodically to check whether a new version exists. The request contains version numbers only — no personal data. The Microsoft Store version performs no update checks at all: updates are delivered exclusively by the Store.

Web panes

Web panes are embedded Microsoft Edge WebView2 browsers. When you open a web page, you are connecting directly to that site, and your activity is governed by that site's own policies — exactly as in any browser. Optional per-pane sandbox mode keeps login cookies isolated between panes, locally on your device.

Local automation features

Transparency about two low-level behaviors, both purely local — nothing is recorded or sent anywhere:

  • Mouse/keyboard hooks: while the app runs it installs low-level hooks so that focus switches correctly between panes (used like global shortcuts). They observe no content and communicate nothing.
  • Agent support (off by default): an optional setting that opens a local-only port so external AI tools on the same machine can drive web panes for automation. It has no remote-control capability and can be switched off at any time.

Data removal

Uninstalling the app removes its settings and stored data (for the Store version, data lives in the app's own container and is removed with it). For any question about data we may hold — in practice only anonymous analytics — contact us and we will help.
